# 24 — Polish the accessible embedded web client

**What to build:** Members can use the complete embedded web experience responsively and accessibly across supported desktop browsers, with local time presentation and a foundation for later localization.

**Blocked by:** 09 — Synchronize Presence, Read Positions, and typing; 10 — Add rich Message interactions; 11 — Upload and safely retrieve Attachments; 12 — Search authorized Message history; 13 — Exchange Direct Messages and enforce Blocks; 14 — Report and moderate Community activity; 17 — Share a screen in Media Sessions; 18 — Moderate live media

**Status:** ready-for-agent

- [ ] Every core flow is operable by keyboard with logical focus order and visible focus.
- [ ] Semantic controls, names, live regions, and status alternatives make messaging and media state understandable to screen readers.
- [ ] Color contrast and reduced-motion behavior meet the documented accessibility floor.
- [ ] Text communication is responsive and usable in supported mobile browsers.
- [ ] Current and previous Chromium and Firefox desktop majors plus current Safari pass the compatibility suite.
- [ ] Mobile-browser calls and screen sharing are presented as best-effort with accurate capability feedback.
- [ ] UTC instants render in the client's timezone and English strings are structured for later localization.
